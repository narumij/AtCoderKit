# 鉄則本の入力形式テスト

`Tests/AtCoderKitTests/Tessoku/` に、全151問の入力形式を扱うテストがあります。

各ファイルは、Foundationの公開入力APIで読み取った結果を`Any`として返すメソッド、自作の入力文字列、結果をキャストして確認するテストメソッドの順です。クエリや組の行はループ内でタプルとして読み、検証用に保存します。

公式入力例の転載許諾を得ていないため、入力データ269件は入力形式に合わせて自作したダミーデータです。公式入力例の転載ではありません。読みやすさを優先した小さいデータを含むため、問題の全制約を満たすジャッジ用データや解法の検証ではありません。

```sh
swift test --filter TessokuInputTests
swift test -c release --filter TessokuInputTests
```
